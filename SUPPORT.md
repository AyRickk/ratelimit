# Support

- **Questions, ideas and deployment help:** [GitHub Discussions](https://github.com/AyRickk/ratelimit/discussions).
- **Bugs and feature requests:** [GitHub Issues](https://github.com/AyRickk/ratelimit/issues/new/choose), with the forms there.
- **Security vulnerabilities:** privately, as [`SECURITY.md`](SECURITY.md) explains.

The project has a single maintainer, so answers come on a best-effort basis. For behaviour that this project shares with envoyproxy/ratelimit, [upstream's documentation](https://github.com/envoyproxy/ratelimit#readme) applies as written.
